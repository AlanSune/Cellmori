## macOS 26 用户反馈

用户明确提供了 MacBook Pro（M4）、macOS 26 和“全部功能已验证”的结论。芯片为 M4；未提供具体机型标识、系统小版本或逐项测试记录；不据此虚构这些信息，也不把该结论扩展为所有 Mac、所有固件的认证。

## 安装与接口

安装器接受 macOS 15.x / 26.x。电池控制仍取决于可读接口、实际写权限和固件响应；“可读”不等于“可写”，“安装成功”不代表全功能验收。

兼容性页面提供系统电池设置入口。本项目不调用 PowerUIAgent 私有限充 API，不绕过 entitlement、SIP 或固件权限。Apple 原生功能以[官方说明](https://support.apple.com/en-my/102338)和实际系统为准。

## 已知边界

电量、温度、电流和供电来源可能异步更新；后台采样、固件决策及调度存在延迟，不能保证精确停在显示的整数百分比。菜单栏以 macOS 报告的供电来源为准，不以电流符号替代。

实验性适配器模式仅清醒且开盖时有效。固件升级可能影响恢复快照；恢复失败时不要先清空记录继续试写。

校准不能修复化学损耗。没有对所有机型、恶意客户端、快速账户切换、部分写入回滚或故障注入完成系统性验收。正式 Release 不改变这些边界，也不等于 Developer ID 签名或 Apple 公证。
