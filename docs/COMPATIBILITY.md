# 兼容性与验证范围

核对日期：2026-11-06。应用与后台目标版本均为 0.6.0。

| 范围 | 状态 |
| --- | --- |
| Apple Silicon / arm64 | 安装包目标；Intel 不支持 |
| macOS 15.x | 安装允许；早期实现曾在 M1 / 15.8.2 观察验证 |
| macOS 26.x | 安装允许，硬件控制尚未实机验收 |
| 其他系统大版本 | 当前安装器不接受 |
| 固件接口写权限 | 运行时检测，按设备和固件而异 |
| Cellmori 全新安装与硬件控制 | 此次更名版本仍待端到端实机验收 |

此前开发记录包含固件限充、回读恢复、短时放电观察和免密码 XPC 握手，不代表所有型号或完整流程已通过。当前纯逻辑检查不访问硬件。

尚未完整验收：完整校准、完整睡眠/唤醒、重启与登录启动、实验性适配器模式、其他型号与新固件、恶意客户端及快速账户切换下的安全行为。不能将“可读”或“安装成功”当作完整功能验收。

## macOS 26

兼容性页面提供接口信息与系统电池设置入口。本项目不调用 PowerUIAgent 私有原生限充 API，也不绕过系统 entitlement、SIP 或固件权限。Apple 的原生充电限制功能应以[官方说明](https://support.apple.com/en-my/102338)和实际系统为准。

固件升级可能改变接口和恢复快照的适用性。若恢复失败，不要清空恢复记录后继续试写；先检查系统充电状态并报告问题。

## 精度和保护

电量、温度、电流和系统供电来源可能异步更新。菜单栏按 macOS 提供的供电来源显示，不以电池电流符号代替供电来源。后台采样、固件决策和调度存在延迟，无法保证在显示的整数百分比处精确停止。

本工具不能修复电池化学损耗、恢复设计容量或提供硬件级安全保证。
