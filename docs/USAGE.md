# 使用指南

## 三种容易混淆的操作

| 操作 | 结果 |
| --- | --- |
| 停止放电 / 取消充满一次 / 停止校准 | 结束临时流程，恢复已保存的日常上限 |
| 交还系统管理 | 停止本程序管理，恢复接管前的固件设置与供电控制 |
| 退出界面 | 关闭菜单栏与历史采样，后台继续维护策略 |

关闭面板会保留菜单栏。是否继续显示 Dock 图标可在偏好设置中选择。

## 日常上限

上限允许 40%–100%，下限是上限减 5%。修改数值后点击“应用上限”；值相同时显示灰色“已应用”。临时流程执行时先停止流程再修改策略。温度阈值为 35–42°C，可在偏好设置调整后应用日常策略。

限充不是立即把电量降低到上限的保证。固件可能自行放电，也可能等待电量自然下降；实际行为以系统读数和固件为准。

## 充满一次

释放本程序限制，等待系统充电至满电，再恢复保存的日常上限。应用会区分等待充电与实际充电。macOS 的充电管理和硬件温控仍然生效，不能保证点击后立即开始充电。

## 接电放电

目标范围为 20%–90%。插着电时暂时让电脑使用电池，达到目标后恢复日常限充。请保持开盖。停止按钮在电量信息下方和菜单栏面板中。

睡眠前会释放主动放电控制；固件后端写入相应睡眠限充范围，唤醒后继续策略。合盖或无法确认开盖时暂停主动放电。MacBook Pro（M4）/ macOS 26 用户报告已验证全部功能；其他设备仍应实际核对。

## 电量校准

流程为充满、累计满电保持 30 分钟、放电至 20%、再次充满。可能持续数小时。临时流程总时限 48 小时，校准放电阶段时限 12 小时；超时后恢复系统管理。该流程不能修复化学老化，不是必须定期执行的维护项目。已有 MacBook Pro（M4）/ macOS 26 用户整体功能验证反馈，具体范围见兼容性文档。

## 温度保护

达到配置温度或低于 5°C 时暂停本程序流程；降至阈值减 3°C 且至少 8°C 后恢复。固件后端可能恢复原固件策略，不等于硬件强制停止所有充电。macOS 始终负责硬件温控。后台约每 15 秒检查一次，阈值不是硬件级即时保护。

## 兼容性页面

- 充电开关接口：直接开启或暂停充电。
- 电量上限接口：把目标交给固件执行；不需要同时存在充电开关接口。
- 适配器控制：切换外接供电与电池供电。
- 独立物理电源检测：避免把主动断开适配器供电误判为拔线。

“已检测到”只表示可读取；实际操作还会核对写入。实验性适配器模式不会自动启用，仅在普通接口不可用且条件满足时允许手动确认。它仅清醒、开盖时有效，可能在睡眠时充过上限，不支持临时充满、手动放电或校准。

## 健康信息

系统最大容量与容量比估算可能不同。故障标记不是完整硬件诊断。功率是电池端电压乘以电流，正值为充入，负值为放出；不能单靠电流符号判断整机供电来源。

## 卸载

1. 关闭登录启动或在系统登录项中移除应用。
2. 在后台服务页点击“卸载”，按系统提示完成管理员认证。
3. 卸载会先恢复接管前设置；恢复失败时停止卸载，以便重试。
4. 确认后台已移除后退出界面，删除应用。个人历史不会自动删除，路径见[隐私说明](../PRIVACY.md)。

高级恢复方式见[故障排查](TROUBLESHOOTING.md)。

## 检查与安装更新

打开偏好设置的“软件更新”，或使用应用菜单/菜单栏里的“检查更新”。只检查 GitHub 正式版，不显示预发布和更旧版本；仓库尚未发布正式版时会显示没有可用更新。

有新版时先查看说明，点击“下载更新”；可取消下载。校验通过后点击“安装更新并退出”，应用会再次核对文件，再打开系统安装器并退出界面，后台仍维护原策略。保留后台组件勾选；安装器验证新版应用和后台后，会以当前登录用户身份自动打开应用。无法自动打开时可从应用程序手动打开。安装需要系统管理员授权。

自动检查默认开启（可关闭），开启后每天最多尝试一次；不自动下载、不静默安装。联网失败会允许重试，不会误报升级成功。校验错误不会进入安装。系统来源确认由用户在 macOS 中完成，应用不绕过安全检查。
