# 故障排查

## 未安装、无响应或版本不匹配

打开“后台服务”，检查 `io.cellmori.helper`、运行 PID、应用/后台版本和最近响应。只读检查可使用：

```sh
launchctl print system/io.cellmori.helper
plutil -p '/Library/Application Support/Cellmori/state.json'
```

后台状态含电池读数、配置、设备使用时间线和签名绑定相关信息，不要直接贴出完整文件。通常先使用应用导出的兼容性报告，并人工检查内容后提交。

## 日常操作仍要求密码

安装、更新和卸载需要密码；日常配置不应逐次请求。先核对运行的应用是否就是安装包中的版本，再使用“验证免密码通信”。不要用修改 sudoers、放宽 root 数据目录权限或关闭签名校验来绕过问题。

## 重建应用后无法通信

开发构建绑定精确代码哈希。重新构建或签名后，使用同一构建的应用更新后台绑定。将同一份、未经修改的应用从构建目录搬到固定位置通常不改变代码哈希，但必须重新检查登录项指向。

## 插电却未充电

“外接供电”不是“正在充电”。临时充满释放本程序上限，但 macOS 或固件可能继续等待。检查温度、系统电池菜单和兼容性错误，不要反复启动校准或强制放电来触发充电。

## 未检测到充电开关

先看电量上限接口。若后者可用，普通限充不依赖充电开关。可读取的接口仍可能在写入时被拒绝。

## 放电如何停止

点击电量信息下方或菜单栏中的“停止放电”，恢复保存的日常上限。要停止所有管理，使用“交还系统管理”。仅退出界面不会停止后台。

## 后台不能正常恢复或卸载

优先使用应用内卸载，它会先尝试恢复设置。高级用户可对自己已核对的安装使用：

```sh
sudo '/Library/PrivilegedHelperTools/io.cellmori.helper' reset
```

或在可信源码目录执行：

```sh
sudo /bin/bash Source/uninstall.sh
```

这些命令会改变电源控制。不要在恢复失败时先删除 `configuration.json`、恢复快照或后台程序。清空文件不能证明硬件已经恢复。

## 提交问题

提供应用/后台版本、macOS、机型、固件、是否接电、当前模式、复现步骤及经过检查的错误文本。不要提交序列号、UUID、管理员密码、签名私钥或完整用户目录。涉及权限绕过或代码执行的问题按[安全政策](../SECURITY.md)私密报告。
