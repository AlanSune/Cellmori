安装内容

应用为必选。后台服务默认勾选，需要管理员授权，可取消勾选，仅使用监测界面。取消勾选不会移除已安装的后台。

后台以 root 运行，路径为 /Library/PrivilegedHelperTools/io.cellmori.helper。启动配置位于 /Library/LaunchDaemons/io.cellmori.helper.plist。

macOS 26 兼容性

  • 普通与固件限充接口自动探测，写入必须回读验证。
  • 部分新固件会拒绝第三方充电控制；允许安装不代表所有功能均可用。
  • 提供兼容性报告及实验性适配器兼容模式。兼容模式必须在应用中手动确认启用，不会随安装启用；仅清醒且开盖时有效，会造成电量往返变化。
  • macOS 26.4 起提供系统原生 80%–100% 限充，应用提供设置入口，不调用私有原生限充 API。

验证范围

当前已在 M1 / macOS 15.8.2 验证固件限充和恢复。另有 MacBook Pro（M4）/ macOS 26 用户报告全部功能正常；芯片为 M4，系统小版本未提供。其他设备与实验模式不作普遍兼容保证。校准不能修复化学损耗。

本地开发签名

应用使用本地 ad-hoc 签名，本安装包尚未使用 Developer ID Installer 签名，也未公证。正式 Release 不等于 Apple 公证。无需关闭 SIP。

安装前请退出正在运行的 Cellmori。安装不会自动启动主动放电、校准、实验兼容模式或登录启动。
